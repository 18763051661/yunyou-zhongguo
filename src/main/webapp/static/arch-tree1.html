★ 标注 = 答辩高频考点

AppConfig（IoC 全量装配 + 启动自举）、OrderServiceImpl（事务状态机）、OrderController（支付收敛）三处最可能被抽查。

五层同名前缀规则

XxxController → XxxService → XxxServiceImpl → XxxDaoImpl → XxxMapper，五层一查到底，新人 10 分钟可定位任何功能。

横切关注点物理隔离

pay/ 与 aspect/ 独立成包：支付通道与审计切面不属于任何业务线，独立演化互不干扰。

配置与代码分离

三大 properties 承载所有环境差异与密钥：换环境改配置不改代码，密钥不进版本库。
